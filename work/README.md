# Generated legacy documentation

Thư mục này chứa script, ảnh render và PDF trung gian của các bản SDS trước migration. Một số file
còn mô tả Chrome Identity/Google OAuth và việc extension gọi Gemini trực tiếp; chúng chỉ được giữ
để truy vết lịch sử, không phải nguồn sự thật cho runtime hiện tại.

Kiến trúc hiện hành nằm tại [`../docs/architecture/ai-gateway.md`](../docs/architecture/ai-gateway.md).
Không chạy lại các script tạo SDS cũ để thay thế tài liệu hiện hành nếu chưa cập nhật toàn bộ nội
dung sang AI Gateway.
